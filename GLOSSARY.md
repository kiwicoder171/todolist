# Couple Task Hub

A collaborative daily task and workflow web application designed for a couple, combining daily routines, urgent ad-hoc tasks, a Kanban workflow, and calendar-based navigation.

## Language

**Household**:
The shared workspace shared between the two partners containing all tasks, routines, and boards.
_Avoid_: Workspace, Organization, Team

**Partner**:
One of the two individuals sharing the Household.
_Avoid_: User, Member, Account

**Assignee**:
The person designated to complete an item: either one of the Partners or Both.
_Avoid_: Owner, Worker

**Routine**:
A recurring habit or checklist item defined once as a template that reappears on applicable days based on its Frequency.
_Avoid_: Recurring Task, Template, Habit

**Routine Frequency**:
The recurrence rule determining which days of the week a Routine appears (e.g., Daily, or selected weekdays like Mon/Wed/Fri).
_Avoid_: Schedule, Recurrence Rule

**Routine Completion**:
The record of a Routine being marked completed on a specific calendar date.
_Avoid_: Check, Habit Log

**Daily Task**:
An immediate, one-off task added for a specific date (e.g., "pick up laundry today").
_Avoid_: Unexpected Task, Ad-Hoc Task, Todo

**Rollover**:
The automatic transfer of an unfinished Daily Task from a past date to today's active list.
_Avoid_: Carryover, Deferral

**Origin Date**:
The initial calendar date a Daily Task was recorded before any Rollover occurred.
_Avoid_: Created Date, Start Date

**Kanban Board**:
A unified, single date-independent board organizing long-term cards into workflow stages with category-based filtering.
_Avoid_: Project Board, Workflow

**Category**:
A customizable label assigned to a Kanban Card to group related items (e.g., "Travel", "Home", "Finance") without creating fragmented boards.
_Avoid_: Tag, Label, Project

**Kanban Card**:
An individual work item or project piece living within a Kanban Board stage.
_Avoid_: Ticket, Task Item

**Stage**:
A vertical column representing a step of progress on the Kanban Board (e.g., Backlog, In Progress, Done).
_Avoid_: Column, Status, Phase

**Day View**:
The dashboard panel showing all Routines, Daily Tasks, and scheduled items for a selected calendar date.
_Avoid_: Daily Panel, Agenda

**Partner Score**:
The cumulative points balance earned by each Partner (+1 for each Perfect Day), allowing negative balances, reduced by consecutive missed day penalties.
_Avoid_: XP, Level, Reward Balance

**Streak**:
The count of consecutive calendar days on which a Partner has achieved a Perfect Day.
_Avoid_: Daily Count, Habit Chain

**Perfect Day**:
A calendar date on which a Partner successfully checks off 100% of their active Routines (personal and shared), earning +1 point.
_Avoid_: Clean Sweep, All Done

**Freeze Day**:
A calendar date marked as a rest, vacation, or sick day that pauses Routine tracking and waives missed-day penalties.
_Avoid_: Off Day, Sick Day, Vacation Mode

**Reward**:
A custom couple privilege with a point cost that can be redeemed using a Partner's Score.
_Avoid_: Perk, Prize, Voucher
