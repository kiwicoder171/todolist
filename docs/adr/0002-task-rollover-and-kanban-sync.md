# 2. Daily Task Rollover and Kanban Two-Way Synchronization

We decided that unfinished Daily Tasks roll forward to today with origin metadata (`rolled_over_from`), while preserving the historical record on the date they were originally created. Additionally, Kanban cards scheduled for "Today" appear directly inside Board 2 (Daily Tasks), and checking them off automatically transitions the card to the "Done" stage on the Kanban board. This eliminates double-entry and prevents unfinished urgent tasks from disappearing in past calendar views.
